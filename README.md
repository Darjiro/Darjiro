## 🚀 Featured Projects

Some of my projects are private, so here is an overview of the products and technical work I am most proud of.

### 🛍️ KeepAll (Founder & Lead Developer)
**[keep-all.com](https://keep-all.com)**

A digital marketplace SaaS that helps creators sell digital content. It uses crypto signatures on Base to provide gasless access to purchases.

- **Main Features:**
  - **Gasless Access:** Uses the **x402 protocol** on **Base**, allowing buyers to access content without paying blockchain gas fees.
  - **Creator Tools:** Custom profile pages (`/@username`), product dashboards, and sales analytics.
  - **Community Automation:** Telegram bots manage exclusive communities by granting or revoking access based on purchases.
  - **Digital Asset Storage:** Assets are stored and served through **Cloudflare R2**.
- **Technologies:** Next.js, FastAPI, MongoDB, Cloudflare R2, Telegram Bots, and Base.

### 💸 Remesas CU — Remittance Platform

A remittance platform rebuilt as a web application, with a Rust backend and a React frontend. The current version brings client transfer workflows and operational tools into one application, with financial data backed by PostgreSQL.

- **Main Features:**
  - Remittance and transfer workflows for clients.
  - Exchange quotes and rate management.
  - Agent and provider operations.
  - Ledger and transaction tracking.
  - A responsive web interface for platform workflows.
- **Technologies:** Rust, Axum, PostgreSQL, SQLx, React, TypeScript, and Vite.

### 🔗 P2P Cryptocurrency Application

A peer-to-peer cryptocurrency exchange application focused on direct communication between users.

- **Main Features:**
  - Transaction workflows designed for reliable exchanges.
  - Direct peer-to-peer communication using WebSockets.
  - A user reputation system to help build trust on the platform.
- **Technologies:** Python, WebSockets, and Docker.
